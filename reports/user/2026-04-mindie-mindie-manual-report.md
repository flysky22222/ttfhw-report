# MindIE 易用性分析报告

## 一、概述

本文档记录MindIE环境搭建过程中遇到的各类问题，按用户生命周期分为四个阶段：了解、安装、使用、贡献。每个阶段记录断点（问题点）及详细用时。

阶段口径统一如下：
- 了解：从主流搜索引擎搜索到对应文档阅读完成。
- 安装：开始尝试从 README 或官方文档提供的安装方式开始下载，到整体安装完成。
- 使用：安装完成后，到跑通 Hello World 或指定场景 case。
- 贡献：按问题数统计，1 个问题按 5 分钟计；没有问题则记 0 分钟。

**总耗时: 约8-9小时**

## 附录B: 问题排查清单

### 安装阶段常见错误

| 错误现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| `externally-managed-environment` | 系统Python保护 | 创建虚拟环境 |
| `undeclared name not builtin: long` | Python 3.12兼容 | 使用Python 3.11 |
| `No matching distribution found` | 网络/版本问题 | 检查pip源，换清华源 |
| `ResolutionImpossible` | 依赖冲突 | 手动安装各依赖 |
| `Install failed` (mindie-service) | 未明确 | 查看详细日志 |

### 运行阶段常见错误

| 错误现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| `undefined symbol` | 版本不匹配 | 对齐torch_npu和mindiesd版本 |
| `No module named 'yaml'` | 依赖缺失 | `pip install pyyaml` |
| `ConfigManager Checking Config Failed` | 配置错误 | 检查config.json配置 |
| 权重加载失败 | 权重路径错误 | 检查权重路径配置 |
